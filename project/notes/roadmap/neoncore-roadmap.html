NeonCore 5G AI Roadmap

From a 5G lab to AI that finds its faults. Status as of 2026-11-12.

Goal: build a 5G core, generate labeled faults, and build AI that finds them, with numbers to prove it. Phases 0 to 6 built the lab. Stages W0 onward move it to Proxmox and add the AI, one stage at a time; each stage has a plan, an owner approval, an independent evaluation and a closing report.

Project specs built on NeonCore

Each AI stage is a new folder in the same repo, so the work reads as one system that grows, not separate demos. Every stage ships with an evaluation number.

NeonCore AI architecture, Stages 7 to 11. The agent sits on top and calls the three AI components as tools; it also reaches the live core through the MCP server, but never changes it without operator approval.

Design rules for all stages

  • The agent reads freely but asks before any change, the same way the CLI already confirms deploy and teardown.
  • Treat logs, pcaps and SBI payloads as untrusted input to the LLM.
  • Record cost and latency next to accuracy; operators decide on all three.

Project ground rules

  • One write-up per finished stage: the problem, a screenshot, the number, what broke.
  • Commit in small steps with clear messages.
  • Never use real operator pcaps, configs or IMSIs, or proprietary documents. NeonCore and synthetic data only.
  • Set a monthly spending cap on API and cloud GPU accounts.
